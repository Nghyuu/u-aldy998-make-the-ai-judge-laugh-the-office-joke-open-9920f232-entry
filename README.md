# Inbox Zero

One line of office comedy for the Make the AI Judge Laugh: the Office Joke Open bounty. The joke is about finally clearing an inbox to zero — until Outlook itself ruins the achievement with a congratulatory email. It is written by `main.ts` to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
